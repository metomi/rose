Fixed a bug where `Runner.run()` (used by `rose task-run`/`rose app-run` and
by extension `rose_arch`) rebound `os.environ` to a new plain `dict` when
restoring the environment after a run, instead of mutating it in place. This
silently broke any code in the same long-lived process that read or wrote
environment variables afterwards (e.g. via `env_export`, `os.environb`, or
any function with a default argument bound to `os.environ`).
