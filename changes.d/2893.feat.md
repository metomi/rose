Add `zstd` and `xz` compression schemes to `rose_arch`, plus a `compress-threads` setting for multi-threaded `zstd` compression. Multi-threaded `zstd` compression prefers the `zstandard` package over the Python 3.14 standard library `compression.zstd` module, and the `ROSE_ARCH_ZSTD_FORCE_CLI` environment variable can be set to always use the `zstd` command line tool instead.
